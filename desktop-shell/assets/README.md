# Icons

`icon.ico` here is a **placeholder** in the product's orange, so the build works
out of the box. Replace it with the real NOKTApp mark before you ship — the same
orange logo/favicon you use everywhere else, exported as a multi-size `.ico`
(256, 128, 64, 48, 32, 16). Keep the file name; electron-builder reads it from
`electron-builder.yml`.

`icon.png` (256×256) is the source the installer uses for the shortcut art.
